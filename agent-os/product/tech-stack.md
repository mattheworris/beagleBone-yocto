# Tech Stack

## Build System

- **Yocto Project / OpenEmbedded** — core build framework
- **BitBake** — task execution engine for recipes and layers
- **Poky** — Yocto reference distribution

## Target Hardware

- **BeagleBone Black** — ARM Cortex-A8 (AM335x) single-board computer

## Bootloader & Kernel

- **U-Boot** — bootloader
- **Linux kernel** — configured and built via Yocto recipes

## CI/CD

- **GitHub Actions** — automated image builds and validation workflows

## Other

- **Shell / Python** — scripting for build environment setup and tooling as needed
